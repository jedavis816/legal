# Privacy Policy

**Last updated:** May 5, 2026

## Overview

This privacy policy applies to a personal SMS automation system operated by a single individual (the "Owner") for personal financial management purposes. The system is not offered as a service to other users, has no commercial customers, and does not collect data from anyone other than the Owner.

## Information collected

The system processes the following data, all generated by or about the Owner:

- SMS message content sent to and from the Owner's personal phone
- Financial transaction data accessed via the Owner's authenticated YNAB account
- Categorization preferences and learned rules derived from the Owner's corrections
- System operational metadata (timestamps, message identifiers)

## How information is used

Data is used solely to provide automated financial status updates, transaction categorization, and budget alerts to the Owner via SMS. Data is not shared with, sold to, or accessed by any third party.

## Storage

Data is stored in encrypted form on Cloudflare infrastructure (D1 database, KV namespace) under the Owner's account. Anthropic API calls are made for natural language processing. Twilio is used as the SMS gateway. Each of these providers operates under their own published privacy policies.

## Retention

Conversation history and transaction metadata are retained indefinitely for the Owner's reference. The Owner may delete any stored data at any time by issuing direct database commands to the system.

## Contact

This system is operated by a private individual. For questions, contact the Owner directly via the SMS interface or through the registered Twilio number.

## Changes

This policy may be updated as the system evolves. Material changes will be reflected in the "Last updated" date above.
